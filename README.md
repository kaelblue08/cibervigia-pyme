# 🛡️ CiberVigía Pyme

> **Plataforma de diagnóstico de ciberseguridad gratuita para pymes latinoamericanas**  
> *Proyecto Personal e Independiente*  
> **Autor:** Jordy Kael Pineda D'Meza · Técnico Superior en Ciberseguridad, Instituto Técnico Superior Especializado (ITSE), Panamá.

---

## 📌 Resumen del Proyecto

**CiberVigía Pyme** es una plataforma web gratuita y de código abierto orientada a dueños de pequeñas y medianas empresas (pymes) en América Latina para diagnosticar si su negocio fue comprometido digitalmente, sin necesidad de conocimientos técnicos.

### ✨ Funcionalidades Principales

1. **🛡️ Chequeo Rápido (~10 min):** Cuestionario interactivo basado en **NIST Cybersecurity Framework** y **CIS Controls**.
2. **🚦 Semáforo de Riesgo:** Indicador visual (🟢 Verde / 🟡 Amarillo / 🔴 Rojo) y puntuación de 0 a 100 pts.
3. **📄 Hoja de Ruta en PDF:** Plan de acción personalizado exportable en formato PDF listo para imprimir.
4. **🧰 Recursos y Plantillas:** Políticas de contraseñas, checklist mensual y protocolo de respuesta a ataques.
5. **👥 Red de Voluntarios Técnicos:** Solicitud de asistencia remota orientada a estudiantes del ITSE y especialistas.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React.js + Vanilla Modern CSS (Design System accesible).
- **Librerías:** `jsPDF` (Exportación PDF), `canvas-confetti` (Animaciones), `Lucide Icons`.
